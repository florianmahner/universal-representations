Image Grouping Study

What you will do

You will see groups of 64 images. A computer model grouped these images together. Your job is simple: decide what the images have in common.

For each group, pick one of these four options:

  • Semantic — the images show the same kind of thing. For example: all animals, all food, all vehicles. The images can look completely different as long as they are about the same topic or concept.
  • Visual — the images look similar. For example: all have the same color, the same shape, the same texture, or a similar image composition. It does not matter what objects are shown — only how they look.
  • Both — the images share both a visual look and a semantic topic.
  • Neither — you cannot find any clear visual or semantic pattern across the images.

Then rate how easy or difficult it was to see what the images have in common (1 = very easy, 7 = very difficult).

There are no right or wrong answers. We want your honest first impression.
